### 👨‍💻 Tentang Saya

Halo! Saya **Muhamad Rofi'i**, seorang pengembang software yang fokus pada pengembangan aplikasi web full-stack, mobile, dan otomatisasi data (*web scraping*). Saya memiliki pengalaman membangun solusi digital end-to-end mulai dari frontend modern interaktif, backend API yang scalable, hingga aplikasi mobile multi-platform.

- 🔭 **Sedang Mengerjakan**: Ekosistem web full-stack (Nuxt.js, Laravel, Django) dan aplikasi mobile berbasis Flutter.
- 🌱 **Sedang Mendalami**: Advanced web automation (Playwright), arsitektur mikroservis, dan Web3/Ethers.js.
- 🎓 **Edukasi & Pelatihan**: Alumnus Dicoding (Backend Developer) & Educourse Web Development.
- 💬 **Bisa Diskusi Tentang**: Vue.js/Nuxt 3, Laravel, Django, Flutter, RESTful APIs, dan Web Scraping.
- ⚡ **Fun Fact**: Gemar membangun aplikasi bertema sosial & lingkungan seperti *Bank Sampah Digital* dan *Smart City*.
